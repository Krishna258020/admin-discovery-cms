## Quick Start

```bash
# Navigate to main directory
cd trekadmin-coupon-panel

# Install dependencies
npm install

# Start development server
npm run dev

# Start backend (in another terminal)
cd backend
npm start
```

## Features

- **Coupon Management System** - Platform, Partner, Special, Premium, Influencer coupons
- **Discovery Manager** - What's New, Top Treks, Trek Shorts with mobile preview
- **Trek Forecast** - Weather forecasts by region
- **Home Themes** - Seasonal themes and campaigns
- **Vendor Management** - Vendor requests and approvals
- **Badge System** - CTA modules for premium vendors
- **Audit Logs** - Complete system activity tracking

For detailed documentation, navigate to `trekadmin-coupon-panel/` directory.
